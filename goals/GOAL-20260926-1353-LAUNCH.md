# GOAL-20260926-1353-LAUNCH: Trend-ready repository launch package

## Intent

The tetris-benchmark repository receives its full launch package — selling README, MIT license, green CI, filled About and topics, fal.ai marketing images, and a generic one-day launch checklist — so a visitor lands on a page that converts and the repo is ready for a concentrated GitHub trending push.

## Problem

The repository works but presents bare: `README.md` holds a single heading, there is no LICENSE, no CI workflow, no repo description or topics, no social preview, and no gameplay demo (session check: `cat README.md` printed only the title line). Nothing today converts a visit into a star for a hype push (user: "make github repsoitory a great repo with all readme md all options filled and it is ready to go to hype in trend board").

## Outcome

Anyone opening the repository on GitHub sees a README with hero banner, badge images, a gameplay demo GIF, and a copy-paste quick start; LICENSE sits at the root; CI runs the three cargo gates on every push; the About line and the six topic tags are set; docs/ holds the fal.ai banner and a 1280 x 640 social preview next to manual upload instructions; docs/launch-checklist.md gives the generic one-day launch steps; and all of it is committed and pushed to main.

## Scope

### In

- README.md: hero banner embed, badge image, gameplay demo GIF, sub-60-second quick start
- LICENSE file with the MIT text
- .github/workflows/ci.yml running the three cargo gates: cargo build --release, cargo clippy --all-targets, and cargo test
- docs/hero-banner.png and docs/social-preview.png (1280 x 640 PNG under 1 MB) generated with fal.ai
- docs/demo.gif showing a real seeded game played by a joined robot
- docs/launch-checklist.md: generic one-day launch steps and timing plus manual social-preview upload instructions
- Repo metadata set with gh: the chosen About description line and the six topic tags
- Commit and push of the package files to main

### Out

- Do not change the Tetris engine, robots, referee, fixtures, scoring, or move words in this goal
- Do not re-run, alter, or embellish benchmark results to change the scoreboard story; present the verified results as they are
- Do not upload the social preview through an API (none exists); deliver the image and manual upload instructions only
- Do not name specific posting channels in the launch checklist; it stays generic
- Do not use paid promotion, star exchanges, or any gaming of GitHub trending

## Context

- Constraints: marketing images are generated through the fal.ai MCP; the social preview is a PNG under 1 MB at 1280 x 640, uploaded manually in repo Settings (no API); GitHub trending rewards star velocity concentrated into one day
- Files / systems: README.md, LICENSE, .github/workflows/ci.yml, docs/hero-banner.png, docs/social-preview.png, docs/demo.gif, docs/launch-checklist.md, gh CLI for description and topics, existing .env stays untouched
- Commands: `cargo build --release` / `cargo clippy --all-targets` / `cargo test`
